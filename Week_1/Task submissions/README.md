# ShopSmart Executive Dashboard 📊

## 📌 Project Overview
The ShopSmart Executive Dashboard is a retail data analytics project developed using **Microsoft Excel** during my internship with **Analyst Lab**.

The dashboard helps analyze sales performance, customer activity, product performance, returns, and inventory through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives
- Monitor key business performance indicators.
- Analyze monthly sales trends.
- Compare revenue across categories and stores.
- Identify top-performing products.
- Analyze sales by state.
- Make business data easier to understand through visual reporting.

## 📈 Key Performance Indicators (KPIs)
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Return Rate
- Inventory Value

## 📊 Dashboard Visualizations
- Monthly Sales Trend
- Revenue by Category
- Revenue by Store
- Top 10 Products by Revenue
- Sales by State

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Excel Tables and formulas
- XLOOKUP and SUMIFS
- PivotTables and PivotCharts
- Interactive slicers
- Dashboard design and PDF export

## 🔍 Interactive Filters
The dashboard includes filters for:
- Year
- Month
- Store
- Category
- Region and Membership Level (planned or dependent on data connections)

## 💡 Key Learning Outcomes
This project helped me develop practical skills in data preparation, data analysis, KPI calculations, data visualization, and interactive dashboard development.

The ShopSmart Executive Dashboard transforms retail data into clear visual insights to support business performance monitoring and decision-making.
